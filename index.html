什麼是遺忘曲線？

心理學家艾賓浩斯的研究指出，新記下的資訊會在短時間內快速流失，唯有在即將遺忘前安排複習，才能把記憶轉為長期記憶。

這份記憶盒會把每一次複習結果即時寫回你的 Excel 檔案，下次開啟同一份檔案即可從原處繼續。

快捷鍵及操作提示

  • 空白鍵　翻面看答案
  • ← / →　上一張／下一張（純瀏覽，不影響複習記錄）
  • Ctrl+→　正面 → 反面 → 下一張正面 → 反面…依序前進
  • Ctrl+←　沿原路依序倒退（反面 → 正面 → 上一張反面…）
  • Enter　標記「已記住」，晉級下一階段
  • Ctrl+S　立即存檔（加 Shift 為另存新檔）
  • Mac 上的 Ctrl 皆可換成 ⌘
  • 點擊卡片或按空白鍵翻面；按住拖曳選字不會誤翻卡
  • ⧉　複製該面文字到剪貼簿
  • ✎　修改這張卡片的內容，儲存後立即同步回 Excel／Google Sheets
  • ✅ 已記住　→ 晉級下一階段，延後下次複習時間
  • ❌ 還沒記住　→ 退回第 1 階段，重新記憶
  • 第 4 階段再答「已記住」→ 完全熟練，自動移出記憶庫
  • 作答模式：正面／反面／遮蔽／輸入，遮蔽與輸入使用 [ ] 標記的內容
  • 複習範圍：先選知識類型，再用張數範圍指定「第幾張～第幾張」
  • 迄預設為該類型到期卡片總張數；手動改過後不再自動更新，按「清除」恢復
  • ⚙　設定自動播放間隔與換行符號（預設「｜」，只影響顯示，不改原始資料）
  • 所有複習設定都會自動記住，下次開啟自動還原

如何連線 Google Sheets

  1. 開啟 Google Sheets，新建一份空白試算表
  2. 點選選單 擴充功能 → Apps Script
  3. 刪除預設的程式碼，貼上下面的 Script，按 儲存（💾）
  4. 點選 佈署 → 新增佈署，類型選「網頁應用程式」，存取層級設為「所有人」，按「佈署」
  5. 複製產生的「網頁應用程式 URL」貼回記憶盒
